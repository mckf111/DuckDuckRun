## 已完成的真实试玩证据

本轮在本地启动当前仓库版本后，实际点击“开始冒险”和第 1 站“明城墙”，观察到四步教学；使用方向键完成换道、跳跃、滑铲和二段跳后进入正式跑局；随后在正式跑局中不再输入，进入失败结算页，看到死因“贴上去了。”、距离、鸭蛋和“起来再跑（Enter）”“分享成绩”“复制链接”“回主菜单”。之后在 844×390 自动化浏览器横屏视口按 Enter 重开，保存了移动横屏实机图。页面控制台本轮没有 error 或 warning。

上述证据是当前 `main` 的本地浏览器证据，不是阶段 5 候选制品的部署证明，也不是实体手机微信兼容证明。发布时不得把本轮自动化试玩得到的“62 m、4 枚鸭蛋”等偶然结果写成成绩或玩家评价。

## 二维码与试玩入口

**二维码验证结果：未生成，因稳定 HTTPS URL 缺失；不存在“验证通过”的二维码。** 仓库内的 `assets/qr-placeholder.jpg` 只是文字占位图，明确写有“二维码暂不生成”“请勿扫码”，不能作为二维码上传。

获得生产 URL 后，按以下顺序处理：

1. 固定部署版本，并记录部署 commit SHA；页面标题和文章实机图必须对应同一版本。
2. 使用无登录窗口打开 HTTPS 地址，检查资源加载、Canvas、音频解锁、菜单、首次教学、暂停、失败和重开。
3. 在实体手机微信中做横屏和刷新烟测；若微信强制竖屏、音频无法解锁或分享异常，不把“微信可玩”写入标题或摘要。
4. 将生产 URL 生成二维码，使用未参与生成的设备实际扫描，确认跳转到同一 HTTPS 地址且首屏可进入当前版本。
5. 替换文章中的“试玩入口”占位句、朋友圈文案中的阻断说明和 `qr-placeholder.jpg`；重新做链接、二维码和图片版本核对后，再由项目负责人手动发布。
