# DuckDuckRun 国内静态部署决策

**决策日期：2026-09-01；候选制品：`dist/releases/1634d51bc5b8/`。** 本文是发布工程与成本估算，不构成关于 ICP、公安备案或第三方素材的正式法律意见；正式上线前应由域名主体/法务核验其适用义务。

> **结论：若已有已备案域名和中国大陆阿里云账号，采用“阿里云 OSS（华东 2 上海或既有合规内地区域）+ 阿里云 CDN 中国内地 + HTTPS 自定义子域名”的纯静态方案。** 它不需要服务器、数据库或容器，且本候选制品已经使用版本目录、内容指纹和根入口原子切换。若没有备案，先采用 OSS 中国香港的 HTTPS 自定义域名作受限预览/备用；它不是大陆节点，也不应被宣传为“国内访问优先”。

## 1. 方案选择

| 条件 | 推荐架构 | 可用性与边界 | 决策 |
|---|---|---|---|
| 已有中国大陆云账号、已备案域名及可配置 DNS | OSS 中国内地区域（优先华东 2 上海；若已有合规 Bucket 则复用）→ CDN 中国内地 → `https://run.example.com/` | OSS 能直接托管 HTML/CSS/JS，CDN 从边缘节点分发；中国内地 CDN/全球 CDN 域名需要工信部 ICP 备案。[1] [2] | **主方案** |
| 有阿里云账号但没有备案域名 | OSS 中国香港 → HTTPS 自定义子域名，不接入中国内地 CDN | 香港 Bucket 自定义域名无需 ICP；官方明确大陆用户访问境外节点可能有跨境网络延迟。[3] | 仅预览/备用，待备案完成后迁移主入口 |
| 只有 GitHub Pages、境外免费托管或 Manus 预览链接 | 仅作为开发预览/验收链接 | 无大陆节点、域名与缓存控制不可按本运行手册保证；不得作为“国内访问优先”主方案。 | 不采用作主站 |
| 已有腾讯云生态与已备案域名 | COS → 腾讯云 CDN 中国内地 → HTTPS 自定义子域名 | 腾讯云官方支持 COS 托管静态资源并由 CDN 分发，费用由 CDN 分发和 COS 回源组成。[4] | 可替代主方案；不因本项目新开双云 |

阿里云主方案优于临时免费托管的原因不是“更时髦”，而是它直接匹配本项目的纯静态、版本化发布模型：版本文件进入不可变的 `releases/<build-id>/`，只有根 `index.html` 和 `build-info.json` 可变。发布不引入账号、后端 API、数据库、常驻进程、PWA 或分析 SDK。

## 2. 官方能力与合规前提

阿里云 OSS 静态网站托管能将 Bucket 内静态文件直接公开为网站，无需传统服务器；文档也明确建议生产环境启用 HTTPS、接入 CDN，并在覆盖文件后刷新 CDN 缓存。[2] 自定义域名通过 DNS CNAME 绑定；官方不建议在根域名直接使用 CNAME，建议使用 `run.example.com` 这类子域名。[3]

| 项目 | 本项目配置 | 前提/责任 |
|---|---|---|
| ICP 备案 | CDN 加速域名使用中国内地节点时必须已有工信部备案号。[1] | 提供备案主体、已备案域名和正确的备案号；如需新增接入按云厂商流程办理。 |
| 公安备案 | 上线后按实际主体和网站性质确认办理。 | 本项目不替代行政/法务判断。 |
| 域名 | 使用二级域名，例如 `run.example.com`。 | 域名所有权、DNS 控制权和到期续费由用户主体负责；年费不纳入下表。 |
| HTTPS | CDN 前置时，在 CDN 配置匹配的有效证书，并强制 HTTP→HTTPS。[5] | 证书可在云证书管理中申请或导入；证书价格/可用免费额度以购置时官方页面为准，未计入下表。 |
| Bucket 权限 | Bucket 保持最小权限；只公开发布资源，部署凭证由 RAM 最小权限账号持有。 | 不将用户上传、密钥或个人数据放入此 Bucket。 |
| 防盗链与日志 | 可启用 Referer 白名单与访问日志；默认不接入行为分析 SDK。 | 日志/安全增值服务可能产生费用，只有确有运维需要才开启。 |

## 3. 月成本估算

下表以阿里云中国站公开按量价格作**保守估算**。OSS 中国内地标准 LRS 存储为 0.12 元/GB/月，CDN 回源流出 0.15 元/GB；阿里云 CDN 中国内地 0–10 TB 下行是 0.24 元/GB，静态 HTTPS 请求为 0.05 元/万次。[6] [7] 当前候选完整首次会话约为 5.69 MiB、约 33 个资源请求；表内按每 1 GB 流量约 180 次完整会话推算，HTTPS 请求成本仅为量级提示。

| 每月 CDN 下行流量 | 固定项（保守按 1 GB OSS 标准存储） | CDN 下行变量 | HTTPS 请求变量（约） | OSS 回源变量 | 合计：高 CDN 命中 | 合计：冷缓存最坏上界 |
|---:|---:|---:|---:|---:|---:|---:|
| 1 GB | 0.12 元 | 0.24 元 | 0.030 元 | 0–0.15 元 | **约 0.39 元/月** | **约 0.54 元/月** |
| 10 GB | 0.12 元 | 2.40 元 | 0.297 元 | 0–1.50 元 | **约 2.82 元/月** | **约 4.32 元/月** |
| 100 GB | 0.12 元 | 24.00 元 | 2.969 元 | 0–15.00 元 | **约 27.09 元/月** | **约 42.09 元/月** |

当前候选版本目录约 6.2 MiB，实际纯存储项约 0.0007 元/月；表中仍按 1 GB 预留，因此更保守。回源不会等于总下行，命中率越高越接近“高 CDN 命中”列；新版本刚发布或大面积刷新缓存时才接近冷缓存上界。**域名注册/续费、证书的商业版本、ICP/公安备案办理成本、税费、安全产品、日志和任何促销资源包均未计入。** 所有价格应在实际下单页再次确认，资源包/活动价不应写死进预算。

## 4. 版本与缓存决策

构建器将所有运行时资源放在 `releases/<12位构建ID>/`，图片与字体使用内容哈希文件名。版本目录内的资源可使用 `Cache-Control: max-age=31536000, immutable`；根 `index.html` 与 `build-info.json` 使用 `Cache-Control: no-cache, no-store, must-revalidate`。部署脚本先上传完整版本目录，再上传根入口，因此用户不会命中半上传的版本。部署后只刷新根入口和 `build-info.json`，**不可**刷新整个 `releases/` 目录或 hash 文件。

阿里云刷新接口会使节点缓存失效，新请求回源获取内容；大范围刷新会增加源站压力，官方说明刷新任务约需 5–6 分钟生效。[8] 因此本项目只刷新两项可变对象，并保留旧版本目录用于即时回滚。

## 5. 需要用户提供的最少信息

当前没有可用的大陆云账号、备案域名、DNS 权限或部署凭证被提供给本任务，因此不存在实际生产 URL，也没有执行生产上传或 DNS 修改。准备生产发布时，只需一次性提供以下信息或在 GitHub Secrets 中配置：已备案的 `run.example.com` 类子域名、所选阿里云区域与 OSS Bucket 名称、CDN 加速域名、最小权限 RAM 部署凭证，以及是否允许在完成实机微信冒烟后执行生产发布/DNS 切换。详细变量、权限、操作顺序、验证与回滚见 [`runbook.md`](./runbook.md) 和 [`rollback.md`](./rollback.md)。
